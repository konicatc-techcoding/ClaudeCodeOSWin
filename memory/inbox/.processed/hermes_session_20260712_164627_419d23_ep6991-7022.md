## AgentOS 的 `episode capture` 是什麼？

若你指的是 **AgentOS／agent learning loop** 裡的 `episode capture`，它的核心目的，是把一次 Agent 執行任務的完整經驗，保存成可供後續**分析、評估、重播與改進**的「episode（回合／軌跡）」。

可以將一個 episode 理解為：

```text
任務輸入
  → Agent 推理／決策
  → Tool calls 與結果
  → 中間狀態、錯誤、修正
  → 最終輸出與任務結果
```

`per-session cursor` 的目的，是讓 **每個 session 各自維護 episode capture 的擷取進度（checkpoint）**，而不是用一個全域 cursor。

## 為什麼需要它？

Agent 的 session 是彼此獨立、且可能同時進行的執行序列：

```text
Session A: user → reasoning → tool calls → result
Session B: user → tool calls → retry → result
Session C: cron job → script → delivery
```

- 哪些 event 已被某個 session 消費；
- 新 event 屬於哪個 episode；
- session A 的晚到 event 是否會被錯過；
- 平行 session 是否造成重複 capture 或交錯寫入。
